# clean-text

Скилл для Claude, который пишет и проверяет тексты так, чтобы они не читались как ответ нейросети.
Работает с русским и английским.

Основа скилла — каталог [petergyang/no-ai-slop](https://github.com/petergyang/no-ai-slop) (лицензия MIT,
файлы скопированы без изменений). Сверху добавлено:

1. **Русский язык.** Исходный каталог только английский. Здесь те же ошибки по-русски, плюс
   канцелярит («осуществлять контроль», «в рамках», «данный») и правила тире.
2. **Факты автора не трогаются.** Правка не добавляет цифр, дат, имён и уточнений и не удаляет
   утверждений автора. Цитаты, юридические формулировки, код, названия и ссылки не меняются. Слова
   степени сохраняют силу: «ключевая роль» не становится «главной причиной», «позволяет сократить»
   не становится «сократятся», «давайте перейдём» не становится «переходим». Скрипт сверяет черновик
   и итог: какие цифры (цифрами и словами, вместе с тыс/млн и %), даты, «в пятницу», цитаты, ссылки
   пропали или появились. Каждое изменённое предложение он выводит парой «было → стало» и помечает
   пару, где пропало отрицание или слово важности, возможности, призыва, обобщения или уверенности.
   Каждую помеченную пару Claude обязан исправить: объяснение флаг не снимает.
3. **Уровень усилия по ставкам.** Сообщение в Slack проверяется за один короткий проход, документ —
   полным циклом, текст для совета директоров или клиента — с двумя независимыми читателями. Лимиты
   жёсткие, бесконечных кругов нет.
4. **Свежий читатель.** Готовый текст читает отдельный экземпляр Claude, который не видел ничего,
   кроме текста и описания читателя, и отмечает каждое место, где читатель споткнётся. Что можно
   исправить без автора, Claude исправляет; остальное уходит вопросами к автору. Работает в Claude
   Code; в claude.ai Claude прямо пишет, что независимого прочтения не было.
5. **Командный глоссарий и личный профиль.** Скилл читает термины команды и личный профиль автора,
   а после каждого текста тихо дописывает в профиль, как этот человек пишет. Со временем у каждого
   получается своя версия скилла.

## Установка в Claude Code

В сессии Claude Code:

```
/plugin marketplace add arturtsg-del/clean-text
/plugin install clean-text@clean-text
```

Обновить до новой версии:

```
/plugin marketplace update clean-text
```

Без системы плагинов можно скопировать скилл вручную:

```bash
git clone https://github.com/arturtsg-del/clean-text.git && clean-text/tools/install-local.sh
```

## Установка в claude.ai и Claude Desktop (вкладка чата)

1. Скачайте `clean-text.zip` со страницы Releases этого репозитория или соберите сами:
   `tools/build-zip.sh`.
2. Settings → Capabilities → Skills → Upload skill, выберите zip.
3. Должен быть включён Code execution and file creation: без него скрипт проверки не запустится, и Claude проверит текст
   только чтением.

## Как пользоваться

Скилл включается сам, когда вы просите написать, поправить или проверить текст. Уровень усилия он
выбирает по ставкам текста и называет в ответе одной строкой.

| Что сказать | Уровень | Что произойдёт |
|---|---|---|
| «Почисти сообщение в Slack» | Быстрый | Одна правка, проверка скриптом, сверка фактов. Без свежего читателя |
| «Напиши пост для команды», «убери слоп» + документ | Стандартный | Полный цикл и один свежий читатель |
| «Прогони лупом до чистого», текст для совета, клиента, инвесторов | Глубокий | Полный цикл и два свежих читателя |
| «Это слоп?», «проверь, не переписывай» | Проверка | Список ошибок с цитатой и коротким исправлением, без переписывания |

Вопросы, на которые может ответить только автор (что такое KPI-4, к какому плану 7%), не держат
цикл: Claude отдаёт текст вместе со списком этих вопросов.

В Claude Code скилл можно вызвать явно: `/clean-text:clean-text`.

Скрипт проверки можно запустить и без Claude, на любом `.md`, `.txt`, `.html` или `.pdf`:

```bash
python3 plugins/clean-text/skills/clean-text/scripts/audit.py draft.md
```

Сверка фактов между черновиком и правкой:

```bash
python3 plugins/clean-text/skills/clean-text/scripts/audit.py draft.md --compare edited.md
```

Код выхода 0 значит только, что регулярные выражения ничего не нашли. Метафоры, преувеличения и
непонятные термины видно лишь при чтении, поэтому чтение каждого предложения в цикле обязательно.

## Командный глоссарий и личный профиль

Оба файла необязательные, это обычный Markdown. Форматы и правила в
`plugins/clean-text/skills/clean-text/references/context.md`.

- **Глоссарий команды** — `.claude/clean-text.md` в общем репозитории команды. Официальные названия,
  термины и их смысл, кто их знает, фразы, от которых команда отказалась. Его ведёт команда; Claude
  только читает и предлагает добавления в вопросах.
- **Личный профиль** — `~/.claude/clean-text/profile.md`. Как пишет конкретный человек: обороты,
  которые он оставляет, слова, которые никогда не использует, его термины, его поправки к прошлым
  правкам. Claude создаёт файл сам при первом запуске и дописывает до трёх строк после каждого текста.
  Явная поправка («верни как было», «я так не говорю») сразу становится правилом; привычный оборот из
  черновика сначала записывается как наблюдение и становится правилом, когда встретится во втором тексте.
  В профиль попадает только стиль: никаких цифр, цитат, данных клиентов. Файл можно править и удалять
  руками, ваши строки Claude не трогает.

Профиль решает вопросы голоса (ваш оборот остаётся, даже если каталог его вырезал бы), но не может
отменить правила о фактах. В claude.ai файлы между чатами не сохраняются: Claude выдаёт новые строки
профиля в конце ответа, а сам профиль можно добавить в знания проекта.

```

  skills/clean-text/

    references/russian.md                типовые ошибки по-русски, канцелярит, тире
    references/decks.md                  слайды, PDF и HTML: проверка по готовому файлу
    references/fresh-reader.md           задание для свежего читателя
    references/context.md                глоссарий команды и личный профиль: форматы и правила
tests/                                   примеры текстов для проверки скрипта
tools/test.sh                            проверка скрипта на примерах
tools/build-zip.sh                       сборка zip для claude.ai
tools/pull-upstream.sh                   обновление каталога из исходного репозитория
```

## Как предложить правку

Нашли ошибку, которую скилл пропускает: добавьте её в `references/russian.md` или в таблицу §5
`SKILL.md`, допишите регулярное выражение в `scripts/audit.py`, положите пример в `tests/slop_*.md` и
запустите `tools/test.sh`. Файлы `no-ai-slop*.md` руками не меняйте, их обновляет
`tools/pull-upstream.sh`.
